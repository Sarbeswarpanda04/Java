# Java Practice Workspace

This workspace contains a few beginner-level Java programs for learning basic syntax and concepts.

## Files

- `hello.java` — simple Hello World example
- `Variables & Data types/variables.java` — demonstrates variable declaration and printing values
- `Variables & Data types/data_type.java` — shows primitive and non-primitive data types

## Run a Java file

From the project folder, compile and run a file with:

```bash
javac hello.java
java hello
```

For the other examples:

```bash
javac "Variables & Data types/variables.java"
java variables
```

```bash
javac "Variables & Data types/data_type.java"
java data_type
```

## Learning Goals

- Understand Java class structure
- Work with variables
- Explore primitive and non-primitive data types
- Print output using `System.out.println()`
